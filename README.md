# آيرون بلس | IRON PULSE 🏋️‍♂️🔥
### موقع النادي الرياضي الأقوى والأعنف — Portfolio Demo Single-Page Website

موقع متكامل واستعراضي أحادي الصفحة (Single-Page Application) تم تصميمه وبناؤه بأسلوب هجومي عالي الطاقة ومظهر بريميوم لنادي رياضي خيالي باسم **"IRON PULSE" (آيرون بلس)** بالرياض، المملكة العربية السعودية.

الموقع مبني بالكامل باللغة العربية أولاً (`dir="rtl"` و `lang="ar"`)، مع استخدام اللغة الإنجليزية للكلمات الضخمة والعناوين البصرية المميزة لإبراز الطابع الرياضي القوي.

---

## ⚡ المميزات والهوية البصرية (Visual Identity)

- **الحالة والمزاج البصري (Mood):** خام، قوي، قتالي، رياضي بريميوم (Raw, Powerful, Intense, Athletic).
- **نظام الألوان:**
  - خلفية سوداء نقية (`#050505`).
  - بطاقات بلون رمادي داكن صخري (`#141414`).
  - لون الإشارة الأحمر الناري (`#FF2D2D`) كلون تمييز أساسي ووحيد مع وهج ليزري.
  - نصوص بيضاء نقية ورمادية عالية التباين.
- **الطباعة والخطوط (Typography):**
  - خط **"Cairo" (Black 900)** للعناوين العربية الضخمة والمقنعة.
  - خط **"Bebas Neue" / "Anton"** للعناوين الإنجليزية الجريئة والمفرغة (Outlined Stroke).
  - خط **"Tajawal"** للنصوص والشروحات وتفاصيل التمارين لسهولة القراءة.
- **التفاصيل الدقيقة:**
  - زوايا حادة ومشطوفة قطرياً (`clip-diagonal` و `4px`).
  - طبقة تغشية سينمائية محببة (Film-Grain Noise Overlay).
  - خطوط ليزرية متوهجة وشبكات أرضية رياضية.
  - مؤشر مخصص تفاعلي (Custom Reticle Cursor) مع تأثير التصويب.
  - تأثير رجفة الشاشة على زر الدعوة للانضمام (`screen-shake-hover`).
  - ألعاب نارية واحتفال بـ Canvas Confetti عند تأكيد الحجز.

## 🏗️ أقسام الصفحة (Page Structure)

1. **الواجهة الرئيسية (Hero):**
   - نص عربي عملاق **"ما فيه عذر!"** يظهر بحركة كشف قناعية (Mask Reveal).
   - كلمة **"NO EXCUSES"** ضخمة ومفرغة بالخط الإنجليزي في الخلفية.
   - أزرار تفاعلية: **"ابدأ الآن واستلم خطتك"** و **"جولة في النادي (فيديو)"** تفتح نافذة استعراض 4K.
   - شريط إحصائي حي: مفتوح 24/7، أجهزة هامر وأولمبية، اعتماد أولمبي.

2. **شريط الكلمات المتحركة (Marquee Ticker):**
   - مسار مزدوج متحرك بلا توقف: `STRENGTH • POWER • DISCIPLINE • قوة • انضباط • عرق وتحدي • IRON PULSE • بلا حدود`.

3. **لوحة الأرقام (Numbers & Stats):**
   - 4 عدادات رقمية متحركة عند التمرير: (+2,850 عضو نشط، 24 مدرب أولمبي، 24/7 ساعات العمل، +190 جهاز هامر سترينث).

4. **برامج التدريب (Programs - Horizontal Scroll):**
   - بطاقات تفاعلية للبرامج الخمسة: (حديد وبناء أجسام، كروس فت ولياقة تكتيكية، ملاكمة وفنون قتالية، استشفاء ومرونة، تحول بدني وحرق دهون).
   - شريط قياس مستوى الشدة والجهد (Intensity Meter).
   - زر **"استكشف تفاصيل البرنامج"** يفتح نافذة منبثقة غنية بالتفاصيل والأهداف.

5. **الكادر التدريبي (Elite Trainers):**
   - 4 مدربين محترفين مع تأثير تحول الصورة من الأبيض والأسود إلى الألوان الكاملة والوهج الأحمر عند تمرير الماوس.
   - شهادات المدرب، سنوات الخبرة، مقولة تحفيزية، وحساب إنستغرام.

6. **جدول الحصص الأسبوعي (Class Schedule):**
   - جدول تفاعلي للأيام السبعة (السبت إلى الجمعة) مع فلاتر التصنيف (حديد، كروس فت، ملاكمة، استشفاء، حرق دهون).
   - مواعيد الحصص، الصالات، المدربين، وزر تفاعلي لتأكيد حجز المقعد.

7. **باقات الاشتراك (Membership Plans):**
   - 3 باقات رئيسية: (شهري، سنوي شامل، 3 أشهر).
   - تمييز باقة **"السنوي الشامل"** بلون الإشارة الأحمر كأفضل قيمة (Best Value).
   - زر **"اشترك عبر واتساب"** يفتح محادثة واتساب مباشرة مع نص مسبق التجهيز ومحدد للباقة المختارة.

8. **قصص التحول الحقيقية (Transformations Slider):**
   - شريط تمرير تفاعلي للمقارنة قبل وبعد (Before & After Slider) مع إمكانية السحب يميناً ويساراً.
   - 3 قصص لأعضاء حقيقيين مع مقاييس التغير في الوزن ونسبة الدهون ونمو العضلات.

9. **حاسبة مؤشر كتلة الجسم (Interactive BMI Calculator):**
   - إدخال فوري للوزن والطول بمؤشرات سحب سلسة.
   - مقياس لوني متدرج يوضح الحالة (نحافة، مثالي، زيادة، سمنة).
   - تقديم توصية رياضية وتوجيه المستخدم مباشرة للبرنامج الأنسب في النادي.

10. **الدعوة للانضمام والفوتر (Join CTA & Footer):**
    - عنوان عملاق **"ابدأ تحولك اليوم"** مع كلمة **"UNLEASH THE BEAST"** في الخلفية.
    - نموذج حجز يوم تجريبي مجاني (الاسم، الجوال، الهدف، المستوى).
    - تفجير قصاصات الورق الاحتفالية (Confetti) عند الإرسال.
    - فوتر شامل: العنوان بالرياض (طريق الملك فهد)، رابط خرائط Google، ساعات العمل 24/7، وسائل التواصل، وحقوق الملكية.

11. **الأزرار العائمة:**
    - زر واتساب عائم أسفل الصفحة مع مؤشر نبضي ليزري للتواصل الفوري.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Vite** — بيئة البناء والتطوير فائقة السرعة.
- **React 19 + TypeScript** — هيكلية نظيفة وقوية مع أمان كامل للأنواع (Strict Typing).
- **Tailwind CSS 3** — تصميم وتنسيق مرن مع نظام مخصص للهوية.
- **Framer Motion** — حركات دخول سلسة وكشف مقنع للنصوص.
- **GSAP & ScrollTrigger** — تحريك متقدم ومربوط بحركة التمرير.
- **Canvas Confetti** — تأثيرات احتفالية عند إرسال النماذج.
- **Lucide React** — أيقونات عصرية وخفيفة الوزن.

## 🚀 طريقة التشغيل محلياً (Run Instructions)

### 1. تثبيت الحزم:
```bash
npm install
```

### 2. تشغيل خادم التطوير:
```bash
npm run dev
```
افتح المتصفح على العنوان المعروض في سطر الأوامر (مثلاً `http://localhost:5180`).

### 3. بناء المشروع للإنتاج:
```bash
npm run build
```

### 4. معاينة نسخة الإنتاج:
```bash
npm run preview
```

## 🎨 دليل التعديل والتخصيص (Customization Guide)

جميع بيانات النادي مفصولة في ملف مركزي لتسهيل التعديل بدون المساس بكود الواجهة:

### 1. تعديل باقات الاشتراك ورسائل الواتساب
افتح الملف: [src/data/gymData.ts](file:///c:/Users/ahmu0/Documents/antigravity/happy-davinci/src/data/gymData.ts)
وابحث عن مصفوفة `MEMBERSHIP_PLANS`:
```typescript
{
  id: 'yearly',
  nameAr: 'اشتراك سنوي شامل',
  price: 3490,
  originalPrice: 5880,
  popular: true, // يحدد ما إذا كانت الباقة مميزة
  features: [ ... ],
  whatsAppText: 'مرحباً! أود الاستفادة من العرض الحصري...'
}
```
لتعديل رقم الواتساب ورقم الهاتف، عدّل كائن `GYM_CONTACT` في نفس الملف:
```typescript
export const GYM_CONTACT = {
  phone: '+966 50 892 3421',
  whatsAppNumber: '966508923421', // بدون علامة +
  addressAr: 'المملكة العربية السعودية، الرياض، طريق الملك فهد',
  ...
};
```

### 2. تعديل جدول الحصص الأسبوعي والمدربين
في نفس الملف [src/data/gymData.ts](file:///c:/Users/ahmu0/Documents/antigravity/happy-davinci/src/data/gymData.ts):
- عدّل مصفوفة `WEEK_DAYS` لإضافة أو حذف الحصص وأوقاتها ومدربيها.
- عدّل مصفوفة `TRAINERS` لتغيير أسماء المدربين، صورهم، شهاداتهم، وحساباتهم.
- عدّل مصفوفة `PROGRAMS` لتغيير البرامج ونسب الشدة وصورها.
- عدّل مصفوفة `TRANSFORMATIONS` لتغيير قصص الأعضاء ونسب تحولهم.

### 3. تعديل الألوان والهوية
- **اللون الأساسي (`#FF2D2D`):** معرف في [tailwind.config.js](file:///c:/Users/ahmu0/Documents/antigravity/happy-davinci/tailwind.config.js) تحت `brand-red`.
- **الخلفية (`#050505`):** معرفة تحت `brand-black`.
- **البطاقات (`#141414`):** معرفة تحت `brand-card`.
يمكنك استبدال كود اللون السداسي في ملف التكوين لتغيير طابع الموقع بالكامل بلحظة واحدة.

## 🚢 النشر على Vercel (Vercel Ready)

المشروع جاهز تماماً للنشر على منصة **Vercel** بدون أي إعدادات إضافية (Zero-Config):
1. ارفع الكود إلى مستودع GitHub.
2. استورد المشروع في لوحة تحكم Vercel.
3. الإعدادات الافتراضية المكتشفة تلقائياً:
   - **Framework Preset:** Vite
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
4. اضغط **Deploy**.
